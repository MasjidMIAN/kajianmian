# Jadwal Kajian Masjid

Buatkan aplikasi formulir pengisian jadwal kajian rutin di Masjid Imam An-Nawawi dengan format google sheet seperti ini:
Tanggal Masehi|Tanggal Hijri|Pemateri|Ket. Pemateri|Judul|Ket Tambahan|Umum/Khusus

Pengisian dilakukan oleh panitia/DKM. Setelah submit, data masuk ke google sheet. Dan ada pemberitahuan melalui whatsapp ke nomor pengurus/admin berisi data yang sudah diisi.
